# AGRILINK — FASE 1

## DESIGN SYSTEM PREMIUM, PROPRIETÁRIO E ESCALÁVEL

### CONTEXTO

Estamos a reconstruir a experiência visual da **AgriLink**, uma plataforma AgriTech que conecta produtores, vendedores, compradores e transportadores, permitindo descobrir produtos agrícolas, publicar ofertas, negociar, realizar pedidos, organizar transporte, efetuar pagamentos e acompanhar operações.

A AgriLink deve transmitir:

**TECNOLOGIA + AGRICULTURA + COMÉRCIO + LOGÍSTICA + CONFIANÇA + ESCALA**

O objetivo desta fase é criar a **fundação visual e comportamental definitiva da AgriLink** antes de redesenhar as restantes áreas do produto.

Não quero apenas uma biblioteca de componentes.

Quero uma linguagem visual própria, coerente e reconhecível.

---

# 1. OBJETIVO PRINCIPAL

Criar um Design System completo para a AgriLink que seja:

* Premium
* Moderno
* Tecnológico
* Futurista
* Profissional
* Editorial
* Operacional
* Escalável
* Responsivo
* Acessível
* Consistente
* Visualmente distinto
* Adequado para agricultura, comércio e logística

A interface deve parecer construída por uma **equipa profissional de Product Design + UX + UI + Engineering**, e não por um gerador automático de interfaces.

O sistema deve funcionar como a identidade visual base de toda a plataforma.

---

# 2. REGRA MAIS IMPORTANTE

## NÃO CRIAR UMA INTERFACE COM APARÊNCIA DE IA.

Evitar deliberadamente padrões visuais excessivamente associados a interfaces genéricas produzidas por ferramentas como:

* Lovable
* v0
* Bolt
* templates SaaS
* dashboards genéricos
* UI kits de startups
* landing pages de ferramentas de IA

A AgriLink deve ter personalidade própria.

### NÃO FAZER:

* Tudo dentro de cards arredondados
* Todos os cards com grandes border-radius
* Sombras exageradas
* Gradientes verdes genéricos
* Glassmorphism excessivo
* Backgrounds com blobs
* Glow neon sem função
* Excessivas pills
* Badges em todos os elementos
* Ícones ao lado de absolutamente todos os textos
* Estatísticas sempre apresentadas em 4 cards iguais
* Grandes espaços vazios sem função
* Layouts repetitivos de 3 colunas
* Botões gigantes sem necessidade
* Hero sections genéricas
* Ilustrações SaaS genéricas
* Componentes visualmente idênticos aos templates de IA
* Uso excessivo de verde apenas porque o produto é agrícola

### REGRA:

**Agricultura não significa obrigatoriamente “interface toda verde”.**

A identidade deve representar agricultura através de:

* matéria
* território
* produção
* movimento
* comércio
* dados
* infraestrutura
* confiança
* precisão

Isto parece um template SaaS?

### 2.

Isto parece gerado por IA?

### 3.

### 6.

O componente realmente melhora a operação?

O Design System só deve ser considerado concluído quando:

* existe uma identidade visual clara
