# Manual Comercial AgriLink — GitHub Pages

Versão estática e independente do manual comercial desenvolvido na aplicação AgriLink.

## Publicação

- Caminho publicado: /sales-playbook/
- URL esperada: https://theruralteam.github.io/agrilinks/sales-playbook/
- Fonte: docs/sales-playbook/
- Workflow: .github/workflows/pages-sales-playbook.yml

O workflow prepara apenas esta página estática e publica-a no GitHub Pages. Não depende de React, Vite, Supabase, Vercel, variáveis de ambiente ou serviços pagos.

## Funcionalidades

- Layout responsivo para telemóveis e computadores.
- Índice de 18 secções com pesquisa.
- Guiões comerciais com cópia para a área de transferência.
- Ficha de prospecção preenchida localmente no navegador e opção para copiar o resumo.
- Impressão e exportação para PDF através do navegador.
- Link para o domínio oficial AgriLink.

## Privacidade e publicação

**GitHub Pages é publicação web pública.** O conteúdo desta página pode ser consultado por qualquer pessoa que conheça ou encontre o endereço. Não existe autenticação nem controlo de acesso por utilizador nesta versão.

Não introduzir aqui dados pessoais, credenciais, informação de clientes, dados operacionais restritos ou condições comerciais não aprovadas para divulgação pública. Os valores de taxas apresentados no manual estão identificados como sujeitos a confirmação da política comercial vigente.

## Actualização

Editar o ficheiro index.html nesta pasta. A publicação é accionada automaticamente após a integração das alterações na branch main, ou manualmente pelo workflow Publish AgriLink Sales Playbook.
